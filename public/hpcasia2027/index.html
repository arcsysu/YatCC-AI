BEFORE YOU JOIN

A few practical details.

Have a specific question? Get in touch.

Do I need experience with YatCC or LLM serving?

No prior YatCC experience or GPU administration experience is required. The tutorial is intermediate overall, but introductory walkthroughs make it accessible to participants new to LLM serving. Basic Python or shell and batch-job concepts will help.

Will agents run generated code automatically?

The guided workflow includes an explicit human review and approval step before computation is submitted. Participants inspect the proposed code, adjust parameters and check results against reference outputs, while preserving the execution record.

What if live generation or connectivity is unavailable?

The tutorial plan includes reference scripts, prepared outputs, screenshots and recorded demonstrations as fallback materials. These support discussion and verification when live services are unavailable; hands-on hosted access still requires connectivity.

Can I adapt the workflow for my own institution?

Yes—the reference architecture and reusable workflow template are intended to support adaptation. Institutional deployment must account for model access, scheduler policies, resource isolation, permissions, data staging and budget limits. The closing discussion covers these trade-offs.
